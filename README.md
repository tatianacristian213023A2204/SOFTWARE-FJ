
# SOFTWARE FJ

## Sistema Integral de Gestion de Clientes, Servicios y Reservas

### Descripcion del proyecto

Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios y reservas mediante programacion orientada a objetos.

El sistema utiliza clases, herencia, encapsulamiento, abstraccion y polimorfismo para organizar sus funcionalidades.

### Objetivo general

Desarrollar un sistema integral que permita administrar clientes, gestionar diferentes tipos de servicios y controlar las reservas de manera organizada y segura.

### Funcionalidades

- Registro y validacion de clientes.
- Gestion de reservas de salas.
- Alquiler de equipos.
- Gestion de asesorias especializadas.
- Calculo de costos con impuestos y descuentos.
- Confirmacion, cancelacion y procesamiento de reservas.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores en archivos de log.
- Ejecucion de pruebas de funcionamiento.

### Tecnologias utilizadas

- Python 3.13
- Visual Studio Code
- Programacion orientada a objetos
- Git y GitHub

### Estructura del proyecto

- excepciones.py: excepciones personalizadas.
- entidades.py: clase abstracta general.
- clientes.py: gestion de clientes.
- servicios.py: clases de servicios.
- reservas.py: gestion de reservas.
- main.py: programa principal.
- logs/registro.log: registro de eventos y errores.

### Ejecucion del programa

Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

```bash
python main.py
```
